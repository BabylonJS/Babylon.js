Source: https://github.com/KhronosGroup/glTF-Test-Assets-Interactivity/tree/main/Models/PhysicsMath/glTF

The sample simulates collisions with KHR_interactivity math operations. It has
no engine physics bodies or collision event declarations. Click a ball during
playback to reset its position.
