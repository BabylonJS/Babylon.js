Babylon.js shared ui components
=====================

This is a collection of UI components mainly used in the babylon.js toolset.

The package has no root entry point. Import components from their module paths (for example `@babylonjs/shared-ui-components/fluent/primitives/button`) or from the `@babylonjs/shared-ui-components/lite` entry point.

For further information please visit https://github.com/BabylonJS/Babylon.js
